# 示范图约定

练习页示范区**默认**显示 `practice/fonts` 里 SignPinyin 字体的字形（临时参考，尚未逐项核定）。页面只探测 `approved/{字母ID}_front.png` 正式槽位；该目录当前为空，等获批且许可齐全的参考图放入。缺图时页面明确显示“该项参考图待完善”，不静默回退旧图。

本目录根部的 8 张 `GF0021.*_front.png` 是已被负责人否定的三维渲染图，仅作存档保留，**页面不再读取**；评测工具仍用它们的文件头做尺寸追溯。

## 文件名

```
{字母ID}_front.png
```

例子：

- `GF0021.U_front.png`
- `GF0021.V_front.png`
- `GF0021.A_front.png`

`字母ID` 必须与 `letters.json` 的 `id` 一致，不能叫 `fist1`、`hand_u` 这种私名。

## 视角

| 后缀 | 第一期 |
|---|---|
| `_front` | 必填。掌心可读的正面静图 |
| `_side` 等 | 以后再加，练习页暂不读 |

## 这是什么 / 不是什么

- **不是**标准示范。根目录存档的 Blender 渲染图是按 GF 0021—2019 文字摆的草稿，未经核定，且已被负责人否定，不得再作为默认示范。
- **不是** 识别模型，不进入 MediaPipe，不参与 `evaluate()`。
- SignPinyin 只是缺图时的字形回退，**也不是**识别模型。

渲染脚本应能用 `blender -b` 复现；姿态名与 `GF0021.*` 对齐。

上游：MediaPipe Hand Landmarker Web

2. GF 0021—2019《汉语手指字母方案》

内容层只引用这份国家规范（26 个拉丁字母 + zh / ch / sh / ng / ê / ü）。字母 ID 形如 GF0021.U。主路径练 A B U V L Y I W，其余在图鉴。

我们不发明「我们队的手语」，也不把 ASL 手指拼写当国标内容。争议或易混手型写在字母包备注里，不写进判定口号。

教育部《汉语手指字母方案》官方入口：教育部网站 PDF（在线资料，需联网，不属于本机离线能力）。

3. SignPinyin 字体

本地素材。示范区显示两种 SignPinyin 内容：缺参考图时的字形示意，以及 content/demos/font-reference/ 下由字体导出的临时字形参考图（11 个字母）。两者都按 GF 0021—2019 的文字描述编排，尚未逐项人工核定，不是标准示范；字体参考图只是临时素材，不代表内容获批。

SignPinyin 是字体，不是识别模型。 它不参与关键点检测，也不进入 evaluate()。content/demos/approved/ 槽位保留给未来获批的正式参考图；当前没有获批图片。有争议或依据不足的字母不提供字形参考图，只保留文字限制与上方官方入口。

上游：SignPinyin（本地文件 practice/fonts/SignPinyin-Regular-0.6.ttf，字体内部版本 0.5.4ffbeta2，发布包命名 0.6）。许可：SIL Open Font License 1.1，全文随附 practice/fonts/OFL-SignPinyin.txt；保留字体名称 SignPinyin / SignPinYin。版权所有 © 2025 ErSanSan233 与 Zhang 3-er。

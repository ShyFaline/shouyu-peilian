# 示范图约定

练习页示范区**默认**显示 `practice/fonts` 里 SignPinyin 字体的字形（临时参考，尚未逐项核定）。本目录的 PNG 槽位保留给未来获批的参考图。原 8 张三维渲染图已被负责人否定，2026-09-27 起从默认示范位撤下（渲染管线与候选保留在 `blender/` 存档，未删除素材本身）。缺图时页面明确显示“该项参考图待完善”，不静默回退旧图。

## 文件名

```
{字母ID}_front.png
```

例子：

- `GF0021.U_front.png`
- `GF0021.V_front.png`
- `GF0021.A_front.png`

`字母ID` 必须与 `letters.json` 的 `id` 一致，不能叫 `fist1`、`hand_u` 这种私名。

## 视角

| 后缀 | 第一期 |
|---|---|
| `_front` | 必填。掌心可读的正面静图 |
| `_side` 等 | 以后再加，练习页暂不读 |

## 这是什么 / 不是什么

- **不是**标准示范。历史上的 Blender 渲染图是按 GF 0021—2019 文字摆的草稿，未经核定，且已被负责人否定，不得再作为默认示范。
- **不是** 识别模型，不进入 MediaPipe，不参与 `evaluate()`。
- SignPinyin 只是缺图时的字形回退，**也不是**识别模型。

渲染脚本应能用 `blender -b` 复现；姿态名与 `GF0021.*` 对齐。

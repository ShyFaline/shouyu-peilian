识别在本机完成，视频默认不上传。下面四条是提交包里必须能打开的出处。

1. MediaPipe Hand Landmarker

感知层：摄像头帧 → 21 个手部关键点。模型文件在 practice/models/hand_landmarker.task，运行时在浏览器本机，不经过我们的服务器。

许可：Apache License 2.0。这是识别用的开源模型；我们没有改它的权重，也没有把它训练成「国标字母分类器」。

上游：MediaPipe Hand Landmarker Web

2. GF 0021—2019《汉语手指字母方案》

内容层只引用这份国家规范（26 个拉丁字母 + zh / ch / sh / ng / ê / ü）。字母 ID 形如 GF0021.U。主路径练 A B U V L Y I W，其余在图鉴。

我们不发明「我们队的手语」，也不把 ASL 手指拼写当国标内容。争议或易混手型写在字母包备注里，不写进判定口号。

教育部《汉语手指字母方案》官方入口：教育部网站 PDF（在线资料，需联网，不属于本机离线能力）。

3. SignPinyin 字体

示范区当前默认显示 SignPinyin 字形，作为临时参考：字形按 GF 0021—2019 的文字描述编排，尚未逐项人工核定，不是标准示范。许可：SIL Open Font License 1.1。

SignPinyin 是字体，不是识别模型。 它不参与关键点检测，也不进入 evaluate()。content/demos/ 的图片槽位保留给未来获批的参考图；当前没有获批图片。

上游：SignPinyin

主路径 8 个字母的正面渲染静图曾按 content/demos/{字母ID}_front.png 约定作为默认示范，由 blender/hand_gf0021.blend 离线渲染。2026-09-27 起按负责人意见撤下默认示范位，不再随练习页展示；渲染管线与历史候选保留在 blender/ 作存档，未删除。

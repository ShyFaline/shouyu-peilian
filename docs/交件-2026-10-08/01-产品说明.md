# 01 · 当前版本产品说明

> 基线见 [00-基线与口径](00-基线与口径.md)。本页描述**当前版本**（代码基线 `1c987ed`）实际是什么，不是计划书。

## 一句话

对着电脑或手机摄像头练习**中国国标手指字母**（GF 0021—2019《汉语手指字母方案》）的本机网页陪练：左边是示范手（可拖动旋转），右边是自己的手和实时骨架；比错了，页面用一句指向具体手指的提示告诉你怎么改。识别全部在本机完成，视频不上传。

## 它是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 汉语手指字母（拼写层）陪练 | 手语翻译器、中文词句识别 |
| 本机识别（MediaPipe 21 关键点 + 几何规则） | 云端识别、自训检测网络 |
| 「到位 / 还不到位」+ 一句可执行提示 | 分数、排名、「学会手语」证书 |
| 32 项内容范围（26 + zh/ch/sh/ng/ê/ü） | 国家通用手语常用词表覆盖 |

## 当前版本功能（与代码一致）

- **首页**（`practice/index.html`）：产品介绍、学习入口、自测入口、隐私提示；宣纸风格，不加载摄像头代码。
- **学习页**（`practice/learn.html`）：跟练 / 自测两种模式。
  - 跟练：选字母 → 看示范（7 个字母支持 24 帧拖动旋转）→ 主动点「打开摄像头」→ 实时判定与逐指提示。
  - 自测（`learn.html?mode=test`）：隐藏示范与动作说明，只核静态手型，不泄露答案；通过后记入本机记录（`learn.html#records`，仅存次数与时间，最多 64 行，清浏览器数据会丢失）。
- **判定分层**（`practice/content/letters.json` 的 `practiceStatus`，运行时不升格）：
  - `pose_practice`（9 项：A、B、I、J、L、V、W、Y、Z）：允许判定通过；通过只表示**静态手型**在质量、几何、连续保持门下通过。
  - `pending_review`（18 项）：界面显示「暂不判定」，不记通过，不进自测题。
  - `demo_only`（5 项：E、M、N、S、ê）：仅示范，不判定。
  - `accepted_practice`：**0 项**。
- **默认目标为 A**（提交 `be0abf9`；旧版本默认 U，因 U 内容争议未核定已更换）。
- **示范资产**：A/B/I/L/V/W/Y 七个字母使用 Godot XR 绑定手模（CC0）渲染正面图，并各带 24 帧拖动旋转；U 仍为旧 Human Base Meshes 渲染图（内容争议未核定，无旋转帧）；其余 24 项无静态图，回退 SignPinyin 字体字形（字体不是识别模型）。
- **隐私**：摄像头画面只进本机模型；「导出当前手 JSON」默认关闭，勾选后仅本机下载一帧关键点，不上传；通过记录仅存本浏览器。
- **部署**：GitHub Pages（https://shyfaline.github.io/shouyu-peilian/ ，仅 `practice/` 目录上网）；`practice/**` 推送 main 后先过三组必跑测试门再部署（2026-09-30 三笔提交已实际经过该门并部署成功）。

## 使用前提

- 桌面 Chrome 或支持 `getUserMedia` 的现代浏览器；摄像头要求安全上下文（`localhost`/`127.0.0.1` 或 HTTPS）。
- 首次加载约 17 MB 识别资源（wasm + 模型），之后进缓存。
- 本地运行：双击根目录 `启动服务.bat`，或 `cd practice && python -m http.server 8000`，访问 <http://localhost:8000/>。

## 不声称的事

不替代手语老师；不做医疗、康复、听力诊断；不报「准确率」；不把 ASL、字体字形、3D 渲染当识别依据；「通过」仅代表当前静态手型判定，不代表规范意义上的完整掌握；J/Z 在规范中带轨迹，当前只核静态部分。

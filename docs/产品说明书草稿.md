## 一、产品介绍

**一句话：** 对着电脑摄像头练习**中国国标手指字母**（GF 0021—2019《汉语手指字母方案》）的本机网页陪练：左边是示范手（可拖动旋转查看），右边是你自己的手和实时骨架；比错了，页面用**一句具体提示**告诉你哪根手指该怎么改。

**它解决的事：** 初学者不缺示范图，缺的是**练的时候有人看、错了有人说**。本产品在没有人陪练的时候补上「看 + 指出」这一段闭环。

**怎么用（与页面一致的动作路径）：** 首页选「练习」或「闯关」→ 开摄像头 → 对着示范摆出手型 → 页面反馈「到位 / 还不到位」+ 一句针对具体手指的提示；手没入画、画面里有两只手、指尖出框时分别给出引导 → 改正后再练或切换下一个字母。**不显示分数，不打排名。** 通过记录只保存在本浏览器。

**技术形态：** 浏览器本地运行。手部关键点识别用 MediaPipe Hand Landmarker（模型文件随包分发），**识别全部在本机完成，视频不上传**；字母判定用基于关键点的几何规则，未训练任何检测网络。推荐桌面 Chrome 最新版访问本地静态服务（不使用 `file://` 协议）。断外网后页面与模型仍可加载（未做物理断网演练，【待验证】）。

**内容范围（如实状态，2026-10-02）：**
- 字母依据 GF 0021—2019。教育部官网标准扫描件已本地留档（[standards 留档](standards/README.md)，SHA-256 可重算），全部 32 个字母的文字条目与库内文案差异已整理（见 [内容核定表](内容核定表.md)）。
- 32 个字母按实际能力分三组：**可跟练 9 个**（A、B、I、J、L、V、W、Y、Z，判定器回归覆盖）、**待核对 18 个**、**仅示范 5 个**（M、N、S、ê、ü 等规则暂不可区分或带动态成分）。
- `accepted_practice`（可正式判定通过）字母数 = **0**——全部字母未经领域专家对照规范原图复核，这是有意为之。
- J、Z 在规范中带轨迹，本产品只核**静态手型**；ê/ü 在规范中带晃动，判定器已有晃动规则但保持「仅示范」不开放；M/N/S、E/ê 因几何规则不可区分，标「易混」仅作对照。
- 手指字母是**拼写层**（拼人名、地名、专名），不是国家通用手语的词句；本产品不做整句翻译。

**我们明确不做的事（写进说明书，与页面口径一致）：**
不是手语翻译器；不声称让人「学会手语」，不替代手语老师；不做医疗、康复或听力诊断；不训练自己的检测网络，不报「准确率」；不把 ASL 手型当国标内容；默认不上传用户视频；不做实时跟手虚拟人。

## 二、设计思路

1. **从痛点反推功能，不从模型反推产品。** 痛点是「没人纠错」，所以核心输出是**可执行的一句提示**（指向具体手指）而非分类分数；因此判定层选可解释的几何规则，而不是端到端分类器——分类器说不出「哪根手指错了」。
2. **感知与理解分层。** 感知层（MediaPipe）只出中性几何（21 关键点、左右手、置信度），不含任何字母判断；理解层（本队规则）把「伸直/弯曲/并拢/分开/朝向」映射到每个字母的教令式规则卡（`practice/content/letters.json`）。规则可被人工逐条审读，提示可落到具体手指。
3. **内容从规范来，不从二手资源来。** 手型内容直接对齐 GF 0021—2019 原文文字与图示（已取得官网扫描件并逐条比对，差异与疑点全部公开在核定表中，不遮丑）；ASL、字体字形、Kaggle 图集一律不作内容依据。
4. **诚实拒绝优于将就通过。** 看不清、手出框、尺度信息缺失时，系统报「无法判断」状态而非放行或硬判；未核定的字母不放正式通过（状态分层：仅示范 / 待复核 / 可练习 / 可正式判定——当前全项目无「可正式判定」字母）。
5. **示范是真手，不是字。** 早期示范用指语字体 SignPinyin 过渡；因初学者容易从字形反推手型，示范改为 3D 渲染的手模。2026-10-01 起全部 32 个字母换用 Godot XR（CC0）手模正面图 + 24 帧可拖动旋转图，旧 Human Base Meshes 图全部退役。3D 渲染**不进识别循环**。

## 四、价值或创新

- **补「练」而不是补「看」。** 现有公开资源多为示范视频或检测 Demo；把「本机看手 + 到手指级提示 + 可旋转示范」做成一个可离线使用的练习闭环，是我们检索后未见同类产品覆盖的形态（检索记录见过程篇，结论限定于已检索范围）。
- **国标内容对齐 + 争议透明。** 内容直接对齐 GF 0021—2019；与规范原文不一致的条目（含 U）不掩饰、不自行裁定，挂起并公开证据清单——把「规范合规」做成可审计的过程资产（核定表+检索记录），而不只是一句宣称。
- **隐私即架构。** 识别本机化、导出默认关闭、不上传视频，是架构决定而不是宣传点；同意、匿名、删除流程有成文模板（[知情同意与匿名标注模板](知情同意与匿名标注模板.md)）。
- **可复现工程。** 合成回归、golden 恒等矩阵、渲染抽检与证据索引（[证据索引](证据索引.md)）使每个「做到了」有他人可复查的出处；允许的未知与失败（如渲染图检测率低、U 争议）如实保留。
- **商业价值说明（如实）：** 当前为比赛原型，无商业模式验证；潜在使用方为听障儿童家庭、窗口单位岗前练习、手语社入门教学等。**不写规模承诺**。

## 1. 招来做什么

- **用途**：练习页示范区与可折叠图鉴，由现有 Blender 草稿图改为**真人实拍照片**。主路径 8 个字母（A B U V L Y I W）是页面左栏主图；其余 24 个进图鉴。
- **为什么不用 3D**：第三轮已裁定示范素材以真人照片为主，Blender 第三轮重建暂停（历史渲染与脚本保留）。
- **照片会被谁看到**：练习页与图鉴；若授权到 L4 / L5，还会出现在 GitHub Pages 站点与公开仓库。
- **产出不是识别模型**：示范照片不进入 MediaPipe，不参与 `evaluate()` 判定。它是给人看的标准手。

## 3. 硬性条件（可现场验证，不合格即不录用）

### 3.1 手部能力（本项目的核心筛选点）

不要求会手语，要求**手能做得出下列动作并停稳**。括号内是该动作服务的字母：

1. **五指能独立控制**：单独伸小指（I / J）、单独伸无名指（W 等）。
2. **食、中、无名指同时分开直立**成 W 形（W）。
3. **拇指搭到小指远节指上**（W）——最难的一项，与手掌大小、拇指柔韧度强相关。
4. **拇指搭到无名指远节指上**（V）。
5. **拇指搭到小指 / 无名指中节指上**（M、N）。
6. **中、无名、小指能弯曲且指尖抵到掌心**（L、A、I 原文版）。
7. **四指能并拢无缝、直立**（B、ZH、U 四指版）。
8. **拇指能弯入掌心贴掌**（B）。
9. **食、中指直立、中指能搭到食指上（交叉）**（X 原文版、R 仓库版）。
10. **拇、食指能搭成圆形**（E、F、O）。
11. **食、小指能同时横伸**（Z）；**单指横伸**（NG、ZH）。
12. **拇指能从食、中指之间伸出**（T）。
13. **食指能弯曲成钩**（X 仓库版）。
14. **能稳定保持静态手型 ≥3 秒不抖**：拍摄期间手不晃、不塌。有手部震颤、关节活动受限、近期手部外伤者不合格。
15. **能配合录短视频**：J、Z、ê、ü 需按要求走完轨迹（画钩 / 画 Z / 上下晃两下 / 前后晃两下）。

### 3.2 手部外观

| 项 | 要求 | 理由 |
|---|---|---|
| 手 | **右手为主**（规范 5.1「一般用右手表示」） | 左手须单独登记、按「方向作相应改变」处理，不与右手素材混编 |
| 指甲 | **短、干净、无美甲**：不留长指甲，不做延长甲、贴片、指甲油、彩绘 | 长甲 / 美甲会遮挡指尖接触关系，也会让学习者误解标准手 |
| 饰品 | 拍摄时**摘下**戒指、手表、手链、手环 | 不得出现在示范图中 |
| 皮肤 | 手部无明显伤口、脱皮、红肿；肤色均匀、无显著色差 | 照片是教学参照，要清晰可读 |
| 纹身 / 疤痕 | **手部与可见前臂无纹身、无明显疤痕** | 学习者会把示范图当标准手；有争议时由负责人个案判断，不默认通过 |
| 臂毛 | 前臂可见部分无浓密臂毛（或可接受拍摄前处理） | 同上 |
| 年龄 | **优先 18 周岁以上**；未满 18 周岁须**监护人书面同意**并采取更严格数据措施 | 与知情同意模板一致 |

### 3.3 手位与视角（拍摄要求，示范者需能配合）

- 手自然抬到规范规定位置，不超肩宽（规范 5.2）：
  - **同侧胸前**：A B C D H I J K L M N O Q S T U V W X Y SH（多数）
  - **胸前正中**：E F G R Z ZH CH NG
  - **同侧腹部前**：P（本批唯一）
- 以**观看者角度平视**呈现（规范 5.3）。
- **不拍脸**：构图只取前臂与手；素色背景；不拍身份文件、家庭隐私、可识别背景。

## 5. 授权条件（本项目的红线）

**必须签署示范影像授权书**（模板见 [知情同意与匿名标注模板](知情同意与匿名标注模板.md) §5）。五级授权**逐素材逐项勾选，不勾即未授权**：

| 级别 | 用途 |
|---|---|
| L1 | 本地使用（开发机本机调试、对照规范核对） |
| L2 | 参赛提交（随比赛说明书 / Demo 包提交主办方） |
| L3 | 公开视频（进入公开发布的演示视频） |
| L4 | 网站展示（发布到公开网页，含本项目 GitHub Pages 站点） |
| L5 | 公开仓库再分发（进入公开 Git 仓库，任何人可再下载再分发） |

三条原则（不因招募而放宽）：

1. **参与测试的同意 ≠ 同意公开照片。** 试用同意书只覆盖关键点 JSON 与试用记录；照片 / 视频须**另行签署**示范影像授权。
2. **只露手不能默认免授权。** 手部特写仍属可识别个人信息处理范畴；L3–L5 涉及公开传播，须明示同意。
3. **可随时撤回任一级别。** 撤回后对应级别停止使用并登记；撤回权不因已付报酬而消失。

**本次拍摄的特殊说明（须写进授权书）：** 丙组「冲突记录用」照片与丁组「未对图」照片，**即使签了 L4 / L5 也不会发布**——它们是内部对照素材。授权书应就**这两类照片单独勾选**，避免事后争议。

**不许做的事：** 用 AI 生成图片冒充实拍；用第三方网图；把未授权录像当开源数据集入库。

1. 不能或拒绝签署示范影像授权书。

## 7. 筛选流程（两步，适配「一次拍完」）

### 第一步 · 初筛（线上，示范者自己拍手机照发来）

按下表拍右手、素背景、正对镜头，作为能力初筛，**不作为素材使用**。覆盖 §3.1 的高难度动作：

| 自测照 | 动作 | 考察 |
|---|---|---|
| 1 | 单独伸小指，其余四指握拳 | 五指独立控制 |
| 2 | 食、中、无名指分开直立成 W 形 | W 基础 |
| 3 | 在自测 2 基础上，拇指搭到小指远节指上 | W 最难项 |
| 4 | 食、中指分开直立成 V 形，拇指搭到无名指远节指上 | V |
| 5 | 拇、食指张开，其余三指弯曲、指尖抵到掌心 | L / A |
| 6 | 四指并拢直立、拇指弯入掌心贴掌 | B |
| 7 | 食、中指直立、中指搭到食指上（交叉） | X / R |
| 8 | 拇、食指搭成圆形，其余三指横伸稍分开 | E / F / O |
| 9 | 食、小指同时横伸，指尖朝左 | Z |
| 10 | 握拳，拇指从食、中指之间伸出 | T |

**10 张里做不出 7 张以上者，不进入现场拍摄**——省双方时间。

### 第二步 · 一次到场全拍

对照规范文字逐条核 §2 全部 32 个字母 → 按分组顺序拍摄 → 每张现场登记进 [素材清单](../practice/content/demos/photo-candidates/README.md) §1（含授权范围勾选）→ 照片进 `practice/content/demos/photo-candidates/`（候选目录）。

**替换现用 `*_front.png` 须总控批准**，文件命名 / 格式约定不变（`{字母ID}_front.png`）。

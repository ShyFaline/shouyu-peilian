# 成就单设计稿：升级"查看本机练习记录"（2026-10-02）

## 1. 现状

- 入口：`practice/index.html:43` "查看本机练习记录" → 跳到 `learn.html#records` 面板。
- 现状面板（`practice/learn.html:72` 起）：一个纯文本列表，每行 `跟练 · 字母 A · 3 次 · 时间`，外加"清除记录"按钮。没有汇总、没有视觉反馈，成就感知为零。
- 数据层（本项目是纯静态站点，无服务端，"后端"即本地数据层）：
  - `zhijian.practiceRecords.v1`（`practice/src/progress.js`）：按"字母 × 模式"去重的通过计数，`{letterId, mode, count, lastAt}`，上限 64 条。
  - `zhijian.questProgress.v1`（`practice/src/quest.js`）：闯关已通过字母 id 列表。
  - 注意：闯关模式的通过只写 quest，不写 practiceRecords。

## 2. 设计目标与原则

把记录面板升级为"成就单"：一眼看到累计成果，有点亮、积累、里程碑的成就感。

原则（沿用项目既有约束）：

- 不新增判定、不升格 `practiceStatus`；成就全部由现有数据派生。
- 数据仍只留在本机 localStorage，页面继续明示"仅此浏览器"。
- 不引入框架和新依赖；纯函数 + 直跑 node 测试的现有风格。

## 3. 数据层设计（"后端"）

### 3.1 不迁移旧数据，新增派生模块

新增 `practice/src/achievements.js`（纯函数，无 DOM、无存储）：

- 输入：`progress.entries`、`quest.passed`、`letters`、活跃日列表。
- 输出：
  - `stats`：`{ totalPasses, litCount, practiceableCount, questPassedCount, activeDayCount, streak }`
  - `litWall`：每个可练字母 `{ id, label, lit, count }`（lit = quest 通过或 progress 有记录）
  - `badges`：成就列表 `{ id, title, desc, earned }`

旧用户升级后无需任何迁移，点亮墙和计数立即可用。

### 3.2 新增"活跃日"存储（支撑连续打卡）

连续天数无法从现有数据推出（`lastAt` 每字母只留最后一次），需要新 key：

- `practice/src/practiceDays.js`，key `zhijian.practiceDays.v1`，内容 `{ schemaVersion: 1, days: ["2026-10-02", ...] }`。
- 记**本地日期**（`getFullYear/getMonth/getDate` 拼串），不用 UTC ISO，避免时区把晚上练习记到第二天。
- 写入时机：`notePass` 里通过判定成功且持久化成功时写；去重、按日期升序、上限 400 天。
- `streak` 计算：从今天（或昨天，今天还没练不算断）往回数连续活跃日。
- "清除记录"同时清除此 key。

### 3.3 成就规则表（初版，规则静态写在 achievements.js）

| 成就 | 条件 |
| --- | --- |
| 初露锋芒 | 累计第 1 次通过 |
| 小有收获 | 点亮 5 个字母 |
| 半壁江山 | 点亮 ≥ 一半可练字母 |
| 图鉴集齐 | 点亮全部可练字母 |
| 闯关通关 | 闯关模式全部通过 |
| 三日坚持 | 连续活跃 3 天 |
| 七日之约 | 连续活跃 7 天 |
| 百次磨炼 | 累计通过 ≥ 100 次 |

"点亮"定义：该字母在 quest 或 progress 任一处有通过记录。

## 4. 前端设计

### 4.1 面板结构（`learn.html` #records 区改版）

自上而下：

1. **抬头**：标题改"我的成就单"，保留"仅此浏览器，清除浏览器数据会丢失"说明。
2. **总览条**：4 张数字卡 —— 累计通过 X 次 · 点亮 Y/Z 字母 · 连续 N 天 · 闯关 M/Z。
3. **字母点亮墙**：可练字母按 `letters.json` 原顺序排成格子墙。已点亮：实色底 + 手型字形 + 次数角标；未点亮：灰色轮廓。格子是按钮，点击即 `selectLetter` 选中该字母开始练（成就单直接变成"补差入口"）。
4. **成就徽章区**：徽章卡，已解锁显示名称+达成条件，未解锁灰色+条件提示（"再点亮 3 个字母"式的差额提示更好，做成 `desc` + 动态差额）。
5. **最近记录**：保留现有文本列表，按 `lastAt` 倒序取前 8 条（现在是无序全列）。
6. **清除记录**：挪到最底部，样式弱化。

### 4.2 通过瞬间的成就反馈（`notePass` 增强）

通过时对比成就前后快照，若有新增：

- 新点亮字母：pass-seal 文案升级为 "点亮新字母 A！"。
- 新解锁成就：status 行提示 "解锁成就：三日坚持"。
- 闯关模式维持现有过关提示，不叠加。

### 4.3 入口与视觉

- 首页入口文案改为"看看我的成就单"（`index.html:43`），锚点不变。
- 视觉沿用现有 CSS 变量与米色系；点亮格用手型字形；徽章纯 DOM+CSS，不用图片资源。
- 无障碍：格子带 `aria-label`（"字母 A，已通过 3 次"）；徽章状态不只靠颜色（✓ + 文字）。

### 4.4 降级

- localStorage 不可用：沿用 `persist-note` 提示，成就单显示空态，不渲染假数据。
- 无记录：点亮墙全灰 + 空态文案 "还没有通过记录，去点亮第一个字母"。

## 6. 兼容与风险

- **旧数据**：不迁移 `practiceRecords.v1`；点亮墙、计数立即可用；streak 从升级后首次练习起算（空态文案说明）。
- **条目上限**：`MAX_PROGRESS_ENTRIES = 64`，当前 30 字母 × 2 模式 = 60，刚好够用；今后字母扩容需先调上限（届时点亮墙数据优先从 quest 派生，quest 无上限问题）。
- **隐私口径**：不变，全部本机；清除记录同时清三个 key。
- **测试门禁**：新增测试须加入 AGENTS.md 提交前必跑清单。

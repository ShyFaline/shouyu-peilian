关于指间

学习有据，隐私在手。

指间是手指字母手型陪练，不是翻译器，也不替代完整的手语课程。你主动打开摄像头后，识别才会开始；视频仅在设备上处理，不上传。问题排查工具可手动下载关键点文件，不包含视频。

1. MediaPipe Hand Landmarker

感知层：摄像头帧 → 21 个手部关键点。模型文件在 practice/models/hand_landmarker.task，运行时在浏览器本机，不经过我们的服务器。

许可：Apache License 2.0。这是识别用的开源模型；我们没有改它的权重，也没有把它训练成「国标字母分类器」。

上游：MediaPipe Hand Landmarker Web

2. GF 0021—2019《汉语手指字母方案》

内容层只引用这份国家规范（26 个拉丁字母 + zh / ch / sh / ng / ê / ü）。练习页按内容核对进度分三组：可跟练（已核对且有静态判定）、待核对（能看示范，暂不判对错）、仅示范（只展示）。

我们不发明「我们队的手语」，也不把 ASL 手指拼写当国标内容。争议或易混手型写在字母包备注里，不写进判定口号。

教育部《汉语手指字母方案》官方入口：未找到官方 URL

3. SignPinyin 字体

示范区缺渲染图时，用 SignPinyin 字形占位，避免空白。许可：SIL Open Font License 1.1。

SignPinyin 是字体，不是识别模型。 它不参与关键点检测，也不进入 evaluate()。有 content/demos/ 下的 PNG 时只显示渲染图，不再叠加字体角标——SignPinyin 的部分字形与国标手型不一致（如 U），并放会误导。

上游：SignPinyin

4. 标准手示范

主路径 8 个字母的正面静图在 content/demos/{字母ID}_front.png，例如 GF0021.U_front.png。缺图时练习页回退字体，不报错。逐张来源见 content/demos/manifest.json。

2026-09-30 起，A、B、I、L、V、W、Y 七张正面图改用 Godot XR Tools 右手网格 hand_r.gltf，由 blender/build_godot_hand_candidate.py 离线渲染。网格许可 CC0 1.0 Universal，作者 DigitalN8m4r3 aka Miodrag Sejic（2022）。许可全文：vendor/godot-xr-hands/LICENSE.md。同一网格另由 blender/build_godot_hand_turntable.py 逐字母渲染 24 帧转盘（content/demos/rot/），供练习页左右拖动查看手型各个角度；U 与 J/Z 无旋转帧，保持静态示范或字形。V、W 的 V/W 字形正确，侧面可见拇指搭在屈指上，但拇指与远节是近似接触、并非精确贴面。

U 未替换，仍用此前 Blender Studio Human Base Meshes v1.4.1 的 realistic_hand（许可 CC0 1.0）绑到本仓库 HandRig 后渲染的旧图，因其内容 pending_review 争议未核定。姿态与判定规则仍是本队的；没有把这些手送进识别循环。

上游：Godot XR Tools（新手模七字母）；Blender Demo Files · Human Base Meshes（仍在用的 U 旧图；实际 zip：download.blender.org/demo/asset-bundles/human-base-meshes/）。

3D 示范不是识别模型。 只给学习者对照；不驱动虚拟人跟随摄像头，不把渲染图送进分类器。

5. 本机练习记录

跟练和静态自测若真实通过，本页只在当前浏览器写入最小汇总：字母、模式、通过次数和最近时间。不保存图像、视频或手部关键点，也不上传、不同步到账号。

清除本站的浏览器数据会丢掉这些记录。记录只说明当时静态手型通过过，不代表完整掌握手语。摄像头仍只在你主动打开时向系统申请；本地记录不改变这一授权事实。

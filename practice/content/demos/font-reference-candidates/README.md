## 二、观看约定与字形映射规则（依照上游文档）

1. **左右手与视角约定**：
   - 字体采用**第三人称右手视角**（`Regular` 字形，平视面对演示者的右手）。
   - 观看含义为用户在屏幕前看到的右手示范手型，**严禁左右镜像翻转**（翻转会破坏拇指与掌心方向对应关系）。
2. **大小写字形区别**：
   - 作者文档明确指出：**小写字母对应标准手指字母手型**；**大写字母为特殊艺术手形，不符合手指字母方案**。
   - 导出与映射一律使用标准小写字符（或特定 Unicode 字符），禁止直接传入大写字母渲染。
3. **多字母与特殊字符映射**：
   - 单字母 A~Z 使用小写 ASCII `a`~`z`。
   - 双字母手型在字体中提供了连字或特定预设 Unicode：
     - `CH`：字形为 2019 新版扁 O 手形，对应 OpenType 连字 `ch` 及预设字符 `ĉ` (`U+0109`)。
     - `SH`：字形对应 OpenType 连字 `sh` 及预设字符 `ŝ` (`U+015D`)。
     - `NG`：字形对应 OpenType 连字 `ng` 及预设字符 `ŋ` (`U+014B`)。
     - `ZH`：字形对应连字 `zh`（预设字符 `ẑ` U+1E91 略有微调），但因其国标动作与手型存在结构性未决，列为暂不输出。

### 3. 本轮明确不输出 / 暂不能作为参考的目标

- **GF0021.J / GF0021.Z**：规范包含动态画钩、划 Z 轨迹；静态手型无法表达完整字母，避免误导学员。
- **GF0021.EH (ê) / GF0021.UE (ü)**：规范定义为晃动手型（E/U 指式上下或前后晃动），且 ü 依赖 U 裁定。
- **GF0021.ZH**：文字 OCR 与图示结构尚存争议（小指横伸与并拢出入），暂不输出。
- **GF0021.M / GF0021.N / GF0021.S / GF0021.E**：规则难以区分或握拳包裹细节易混，暂不作为首批静态参考。
- **GF0021.X / GF0021.R**：交叉/弯钩指式与旧版方案及仓库历史描述存在出入，排查未完成。

## 四、图片规格与生成版面说明

1. **尺寸规范**：
   - 交付 `512x512` 像素高质量 PNG 与 `256x256` 像素轻量预览 PNG。
2. **版面规范**：
   - **统一纯白背景**（`RGB(255, 255, 255)`），手型黑色填充（`RGB(0, 0, 0)`）。
   - **留白比例**：目标字形边界（bounding box）最长边缩放至 360 像素（占 512 像素画面的 70.3%），四周保留约 15% 充足居中留白。
   - **抗锯齿处理**：先在 4 倍超采样画布（2048x2048）上排版渲染，再使用 Lanczos 算法下采样至 512 与 256 像素，边缘极度平滑无锯齿。
   - **画面纯净**：只保留手型字形主体，不添加任何字母名称、角标、边框或文字说明。字母名称与说明由外层 Web 页面展示。
3. **不可篡改性**：
   - 严禁手动拖拉拉伸、严禁水平镜像翻转、严禁涂抹手指骨骼结构。

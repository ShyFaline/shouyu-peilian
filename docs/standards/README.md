## 5. 审查口径（防止误用）

1. **文字与图分别审查。** 「两遍 OCR 一致」只说明文字提取稳定，不等于条文含义已核定；**手型图从未判读**，一切图相关结论=待人工。
2. 证据卡是 AI 预审材料，人工复核栏留空即**未复核**；任何人不得据此宣布 accepted。
3. 引用本规范时给「印刷页 + 扫描页」，如「印刷页 2（扫描页 5）」。
4. OCR 疑点清单（优先对图）：I/J 的「食/小」疑读、SH 的角度数字缺失、Z/NG/CH/X/R 等与仓库文案冲突项。详见 [../内容核定表.md](../内容核定表.md) A4。

## 2. 要改的字母（优先级排序）

第一批（有 golden 回归门的 8 个主路径字母，**必做**）：

| 字母 | 新姿态要点（letters.json how 为最终依据） | 现有渲染错在哪 |
|---|---|---|
| I | **食指**伸直朝上，中/无名/小弯曲抵掌心，拇指搭中指中节 | 旧图伸的是**小指**（旧规则残留） |
| U | **食、中、无名、小四指并拢直立**，拇指向掌心弯曲 | 旧图只有食中两指 |
| B | 四指并拢直立，拇指**弯向掌心收起** | 四指分得开、拇指前伸 |
| A | 握拳，拇指竖起指尖朝上，手背向右（侧向镜头） | 拇指横伸而非朝上 |
| V | 食中分开成 V，无名/小弯曲，**拇指横搭在弯曲两指上**（收，不外展） | 拇指外展 |
| W | 食中无名分开，**拇指横压小指上**（收） | 拇指外展 |
| Y | 拇指+小指伸出张开，食/中/无名弯曲 | 小指伸出不明显 |
| L | 拇指侧伸、食指朝上成直角，其余收 | 基本对，顺便核 |

第二批（有正式参考图、无 golden，能做就做）：**J**（食指中节回勾，其余握拳）、**D**（握拳拇指搭中指）、**O**（拇食中指尖相抵成 O）、**G**（食指横伸其余握拳）、**H**（食中并拢直立）、**X**（食中直立交叉）。

第三批（词汇层不可区分的全握类 D/M/N/S/SH/Q 与 E/ê/ü，暂不需要渲染）。

## 3. 工作流程

```bat
:: 0. 对照参考：每个字母先看 docs/standards/letters/{ID}.png 插图 + letters.json 的 how 文字
:: 1. 改角度表：blender/build_godot_hand_poc.py 里的 LETTERS / SPLAY / THUMB / Curls
:: 2. 渲染正/侧面：
blender -b --python build_godot_hand_poc.py -- letters
:: 3. 导出 golden 关键点（8 个主路径字母）：
blender -b --python build_godot_hand_poc.py -- landmarks
::    产出覆盖 practice/src/pose-goldens/GF0021.{ID}.json
:: 4. 跑回归门（必须全绿，且不再出现 "STALE golden GF0021.I/U" 警告）：
node practice/src/pose-goldens.test.js
node practice/src/evaluate.test.js
:: 5. 生成三联评审图（规范插图 | 正面渲染 | 侧面渲染）：
python tools/standard-figures/make_triptychs.py
::    产物在 docs/standards/review/GF0021.{ID}_triptych.png
```

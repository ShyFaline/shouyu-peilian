## 2. 匿名与会话编号规范

| 层 | 编号 | 规则 |
|---|---|---|
| 参与者 | `P1`、`P2`… | 不写可识别姓名；代号—人对应表由队长**单独线下保管**，不进仓库 |
| 会话 | `SYYYYMMDD-P1-01` | 一次连续试用为一个会话；同日同人多会话递增 |
| 样本 | `P1-01-frame0042` | HandFrame JSON 文件名带参与者与会话，无外貌信息 |
| 条件 | 光照（窗光/灯/逆光）、距离档（近/中/远）、镜像（开/关）、手（左/右）、设备、浏览器 | 与 `docs/试用户记录.md` 字段一致，缺失项写「未记录」不补造 |

## 3. 独立人工标注模板（对接总控 P2 数据契约）

每个样本一个标注文件（或一行记录），字段：

| 字段 | 说明 |
|---|---|
| `sampleId` | 同上文编号 |
| `targetLetterId` | 目标字母，如 `GF0021.V`（**目标不是真值**） |
| `sourceGroup` | 四类来源之一：`real`（真人采集）/ `synthetic`（合成点）/ `render`（渲染图）/ `third_party_video`（第三方抽帧）；四组永远分开统计 |
| `expectedVerdict` | 标注人独立判定：`pass` / `fail` / `unknown`；对应层级必须注明：`geometric_single_frame`（几何单帧）/ `quality_single_frame`（质量单帧）/ `sequence_practice`（连续练习状态）——单帧通过 ≠ 练习通过 |
| `expectedIssueCodes` | 预期的问题码列表，如 `index_middle.not_together`；无即空数组 |
| `reviewedBy` | 标注人实名（标注表由队长线下保管）或标注人代号 + 实名映射线下存 |
| `reviewedAt` | 标注日期 |
| `labelVersion` | 标签版本，如 `v1`；复核修改时递增并保留旧版 |
| `confidence` | 标注人自评：high / low；low 的不进准确性分母，单独列 |
| `notes` | 分歧说明，自由文本 |

规则：**标注人不知道系统当次判定结果**（先盲标，后对机器）；调参/修复不得使用与最终评估同一批标注；按参与者划分数据集，同会话相邻帧不跨集合。无标签样本只用于流程测试，**不计任何准确性**。

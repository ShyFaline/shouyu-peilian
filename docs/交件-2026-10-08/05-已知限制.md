# 05 · 已知限制

> 基线见 [00-基线与口径](00-基线与口径.md)。本页汇总当前版本**如实存在的限制**，不包装为「即将完成」。

## 内容与规范

1. **规范原图未人工对照**：全部 32 项只完成文字条目级比对（OCR 双遍），规范附图未逐字母人工核对；`accepted_practice = 0`。
2. **U 争议未裁定**：GF 0021—2019 原文文字为四指并拢直立，仓库规则为二指并拢；U 维持 `pending_review`，不判定、不进自测，示范图保留旧版。
3. **I 存在 OCR 疑读**（「食」疑为「小」），J/Z/ZH/SH/NG/CH/X/R/G/H/E/ê/ü 等条目与仓库文案存在出入或疑点，逐条见 `docs/内容核定表.md` A4 与 `docs/给Grok的变更请求.md`；裁定需领域复核人对照原图。
4. **J/Z 只核静态手型**：规范中的轨迹部分不判定；ê/ü 的晃动不判定。动态判定层仅有设计方案（`docs/动态判定层方案.md`），未实现。
5. **M/N/S、E/ê 规则不可区分**：标为「仅示范」，不假装能分。
6. GF 0021—2019 的现行有效性未在官方标准库确认；发布公文页未定位（检索记录见 `docs/GF0021-2019检索记录.md`）。

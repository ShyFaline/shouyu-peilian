## 2. 参考标准与手型结构

1. **依据标准文件**：
   - 《汉语手指字母方案》（GF 0021—2019）
   - 印刷页 2 / 扫描页 5（`docs/standards/pages/hp05.png`）：
     > 「右手拇指向掌心弯曲，食、中、无名、小指并拢直立，掌心向前偏左。」
   - 印刷页 7 / 扫描页 10：
     > 使用规则「一般用右手；用左手时方向作相应改变」、「5.2 同侧胸前」、「平视图观看者角度」。
   - `docs/standards/cards/B.md`：
     > 「B 在 2019 版『呈现角度调整』名单，示范视角以 2019 图为准。」

2. **手型与解剖细节表现**：
   - **示范手与手性**：严格画为**右手**。正面平视观察下，食指位于手内侧偏左（桡侧），小指位于手外侧偏右（尺侧），大鱼际位于左侧。
   - **四指比例与拱弧**：中指最高，无名指次之，食指略低于无名指，小指最短；指根掌指关节（MCP）向小指方向自然倾斜，呈现真实生理拱弧。
   - **拇指弯曲扣合**：自左侧大鱼际起，经掌指关节与指间关节自然向掌心中央横折扣贴，指尖指甲朝向微侧向外，关节折角清晰，接触支撑关系明确。
   - **掌向与立体透视**：掌心向前微偏左（向观看者右侧产生微弱透视内收），手掌右外缘有平缓阴影衬托立体体积感。
   - **风格与阴影**：纯二维矢量平面阴影（Cel-shading），彻底弃用位图高斯模糊/feDropShadow，深色清晰轮廓线（#2B1810，7px），在 256px 缩放尺寸下四指并拢分界与拇指扣贴关系依然清晰锐利。

## 3. 审查与修订过程记录

- **第一版试制**：完成基础矢量绘制与 512px/256px/1024px 渲染。
- **DS/judge 第一轮审查反馈**：指出三项关键结构缺陷：
  1. 左右手解剖朝向颠倒（画成左手掌心向前）；
  2. 掌指比例偏僵硬，四指无生理拱弧；
  3. 滥用 `feDropShadow` 模糊滤镜，且拇指扣合关系不直观。
- **第二版集中修订**：
  1. 全面重构为标准右手正面观结构，修正大鱼际、小鱼际与手指排列；
  2. 重构四指长短比例阶梯与掌骨连接弧线；
  3. 剔除滤镜，全部改用矢量平面多边形投影与指节折痕线；
  4. 完善标头字母、右手视角胶囊与教学要点文字。
- **DS/judge 复核裁决**：**PASS（通过）**。各项解剖朝向、比例与平面表现手法均达标。

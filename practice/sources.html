本页说明用了谁的什么。产品是陪练，不是翻译器，也不发「已学会手语」证书。

识别在本机完成，视频默认不上传。下面四条是提交包里必须能打开的出处。

1. MediaPipe Hand Landmarker

感知层：摄像头帧 → 21 个手部关键点。模型文件在 practice/models/hand_landmarker.task，运行时在浏览器本机，不经过我们的服务器。

许可：Apache License 2.0。这是识别用的开源模型；我们没有改它的权重，也没有把它训练成「国标字母分类器」。

上游：MediaPipe Hand Landmarker Web

2. GF 0021—2019《汉语手指字母方案》

内容层只引用这份国家规范（26 个拉丁字母 + zh / ch / sh / ng / ê / ü）。字母 ID 形如 GF0021.U。主路径练 A B U V L Y I W，其余在图鉴。

我们不发明「我们队的手语」，也不把 ASL 手指拼写当国标内容。争议或易混手型写在字母包备注里，不写进判定口号。

教育部《汉语手指字母方案》官方入口：未找到官方 URL

3. SignPinyin 字体

示范区缺渲染图时，用 SignPinyin 字形占位，避免空白。许可：SIL Open Font License 1.1。

SignPinyin 是字体，不是识别模型。 它不参与关键点检测，也不进入 evaluate()。有 content/demos/ 下的 PNG 时，字体只作为角标。

上游：SignPinyin

4. Blender 手型示范草稿

主路径 8 个字母的正面静图在 content/demos/{字母ID}_front.png，例如 GF0021.U_front.png。由 blender/hand_gf0021.blend 离线渲染；缺图时练习页回退字体，不报错。

2026-09-23 起网格改为追加 Blender Studio Human Base Meshes v1.4.1 的 realistic_hand（许可 CC0 1.0），再绑到本仓库 HandRig 上摆 GF 0021 草稿姿态。姿态、判定规则仍是本队的；没有把这只手送进识别循环。

上游：Blender Demo Files · Human Base Meshes（实际 zip：download.blender.org/demo/asset-bundles/human-base-meshes/）。

这些图是草稿示意，未经官方或专家核定，不作为标准示范。

Blender 示范不是识别模型。 3D 手只给学习者对照；不驱动虚拟人跟随摄像头，不把渲染图送进分类器。

授权原则：

- 撤回权：示范者可随时撤回任一级别授权，撤回后对应级别停止使用并登记。

## 3. 拍摄规范（执行用，与素材卡配套）

- **优先不拍脸**：构图只取前臂与手；不拍身份文件、家庭隐私、可识别背景；素色背景。
- 默认**右手**（规范 5.1）；如示范者用左手，须单独登记并按「方向作相应改变」处理。
- 视角：以**观看者角度**呈现（规范 5.3 平视图约定）；学习者镜像模仿的页面呈现关系由页面另行说明，素材本身按观看者视角拍摄。
- 每个目标至少 1 张正面图；条文涉及接触关系或遮挡的，按素材卡加拍辅助视角/局部图（辅助图为教学补充，不谎称规范规定角度）。
- 现场记录：拍摄日期、示范者匿名 ID、光照、是否镜像显示参照；记录人签字。
- **不得用 AI 生成图片冒充实拍**；不得用第三方网图。
